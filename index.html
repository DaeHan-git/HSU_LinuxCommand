리눅스 명령어 · 핵심 옵션 · 문법 · 활용 예시를 한눈에

사전에서 추가·수정한 내용은 먼저 현재 브라우저에 저장됩니다. 공용 사전을 업데이트하려면 ‘GitHub 갱신’을, 개인 사전 파일을 보관하려면 ‘나만의 사전으로 저장’을 이용하세요.

즐겨찾기와 학습 상태는 현재 브라우저에만 저장되며, 다른 기기와 자동으로 동기화되지 않습니다.

기호 구분 설명 및 기능 사용 예시
| 파이프라인 앞 명령어의 출력을 뒷 명령어의 입력으로 전달 ls -l | grep .txt
> 표준 출력 명령어 실행 결과를 파일에 덮어쓰기(Overwrite) ls > file_list.txt
>> 표준 출력(추가) 명령어 실행 결과를 파일 끝에 덧붙이기(Append) echo "log" >> app.log
< 표준 입력 파일의 내용을 읽어 명령어의 입력으로 전달 sort < fruit.txt
2> 표준 에러 오류 메시지만 파일로 리다이렉션 저장 du -sh /etc 2> error.log
2>>표준 에러(추가)표준 에러를 기존 파일 끝에 덧붙이기ls /없는경로 2>> error.log
&>표준 출력 + 에러표준 출력과 표준 에러를 함께 덮어쓰기ls /tmp /없는경로 &> result.log
&>>표준 출력 + 에러(추가)표준 출력과 표준 에러를 함께 덧붙이기ls /tmp /없는경로 &>> result.log

📁 주요 리눅스 디렉터리 (경로)

디렉터리명 (경로)의미
/이름 없이 슬래시(/)로 표시하는 루트 디렉터리로, 모든 파일과 디렉터리의 최상위 경로
/bin기본 명령어 바이너리 파일이 저장된 디렉터리로, 일반 사용자가 사용할 수 있는 명령어들이 실행 파일 형태로 위치
/dev장치 파일이 저장된 디렉터리로 문자 장치 파일, 블록 장치 파일 등이 존재함. 예) 하드 디스크 장치 파일 → /dev/sda1
/etc시스템 설정 파일들이 저장된 디렉터리로 사용자 계정 정보, 문서 편집기 설정, 네트워크 설정 정보들이 존재하는 위치
/home사용자 홈 디렉터리들이 위치한 디렉터리로 각 사용자의 고유 서브 디렉터리가 존재. 예) 사용자 pi의 홈 디렉터리는 /home/pi
/sbin시스템 관리 명령어 바이너리 파일이 저장된 디렉터리로 root 사용자나 관리자가 주로 사용하는 명령어가 저장됨
/var가변 데이터 파일들이 저장되는 디렉터리로 로그 파일, 캐시 파일, 임시 파일(재부팅 시에도 존재) 등이 존재함
